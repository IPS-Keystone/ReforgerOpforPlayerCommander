## Summary (short field)

Lets a player run OPFOR as a proper commander role with enforced limits — the fair-play rules other units keep on the honour system, kept in code instead.

## Description

Most milsim units let a game master or role-player run the enemy and trust them to play fair. This mod makes the OPFOR commander a real, constrained role: a player commands the opposing force with tools scoped to what a commander could actually know and do, so the fight stays challenging without metagaming.

Designed for op nights where the mission maker wants a thinking enemy rather than scripted AI, and the unit wants the fair-play rules enforced by the game rather than by trust.

Built for the IPS-Keystone unit and shared for anyone running player-led OPFOR. Author: Shrike. Questions and bug reports: Discord (TBC).
